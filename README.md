# claude-agents.nvim media

The images the README on `main` shows. They live on this branch of their own so that installing or cloning the plugin never downloads them. `demo/render.sh` on `main` records them.

- `hero.gif` — the agents view: two agents at work beside the project's earlier conversations
- `hero.png` — a still of the same view
- `live-cursor.gif` — the live cursor following Claude through a file as it reads and edits it
- `diff-accept.gif` — a proposed edit shown as an inline diff and accepted with `:w`
- `agents-switch.gif` — reading a session: an Activity edit, a Changes file and a subagent opened with `<CR>`, then the next session, flagged
